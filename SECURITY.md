# Security Policy

To report a security vulnerability, please use GitHub's
[private vulnerability reporting](https://github.com/Talk2View/talk2view-python/security/advisories/new)
on this repository, or contact us via
[talk2view.com/resources/contact](https://talk2view.com/resources/contact).

Please do **not** open a public issue for security reports. We aim to acknowledge
reports within 3 business days.
