# Talk2View Python SDK

Add AI-powered natural-language control to desktop and Python applications — the
Python counterpart to the [`@talk2view/sdk`](https://www.npmjs.com/package/@talk2view/sdk)
TypeScript SDK.

> **Beta.** This early release reserves the `talk2view` package name on PyPI. The
> full SDK — the `Talk2View` client, tool registration, and streaming — lands in an
> upcoming release. Until then, use the
> [TypeScript SDK](https://github.com/Talk2View/talk2view-typescript) or
> [request a partner key](https://talk2view.com/resources/contact?subject=partner-key)
> to get started.

## Install

```bash
pip install talk2view
```

```python
import talk2view
print(talk2view.__version__)
```
