# talk2view

**This is a placeholder.** It reserves the `talk2view` name on PyPI for the
upcoming Talk2View Python SDK, which is not released yet. Installing it gives you
an empty package: there is no API, and `talk2view.__version__` is the only thing
it exports.

Despite the `b2` in its version number, this is not a beta. The pre-release tag
only keeps the version in order: after 0.2.0b1 and before 0.2.0.

## Where to go now

- **Documentation:** [docs.talk2view.com](https://docs.talk2view.com)
- **TypeScript SDK:** [`@talk2view/sdk` on npm](https://www.npmjs.com/package/@talk2view/sdk)
- **Partner key:** Talk2View is in private beta.
  [Request a partner key](https://talk2view.com/resources/contact?subject=partner-key)
  through the contact form.
